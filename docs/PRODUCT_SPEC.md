# Meta Creative Intelligence SaaS — MVP Product Spec

## Product promise
Turn a business brief into differentiated Meta ad hypotheses, copy and creative directions, then learn from live Meta performance to generate better next iterations.

## Core loop
1. Create workspace and brand profile.
2. Write campaign brief: product, offer, audience, objective.
3. AI creates personas and advertising hypotheses.
4. Generate copy for each hypothesis.
5. Generate static creative briefs/assets in 4:5 first; later 1:1 and 9:16.
6. Connect Meta ad account.
7. Import campaigns, ads, creatives and performance.
8. Map performance back to the generated hypothesis/creative.
9. Produce evidence-backed insights and next-batch recommendations.

## MVP screens
- Sign in / sign up
- Workspace onboarding
- Dashboard
- Brand profile
- New campaign brief
- Strategy output: personas + angles
- Copy studio
- Creative studio
- Meta connection
- Performance dashboard
- Creative detail / lineage
- Settings

## Must-have product principle
Every generated ad belongs to a hypothesis. Never generate six cosmetic variants with no strategic distinction.

## Not in MVP
- Automatic budget changes
- Automatic pausing of ads
- Full campaign publishing
- Video editor
- Team permissions beyond basic workspace membership
- Competitor scraping
- Fully autonomous media buying

## Phase 2
- Publish ads to Meta as PAUSED by default
- Creative fatigue detection
- Automated scheduled performance sync
- Winner-to-variation generation
- Team seats
- Shareable client reports
- 1:1 / 9:16 resizing
- Video creative generation

## Moat
The key dataset is creative lineage + hypothesis + account-specific performance. Over time the system should learn which hooks, offers, angles, formats, visual styles and copy patterns work for each account.
